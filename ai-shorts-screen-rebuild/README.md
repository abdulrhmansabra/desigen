# AI Shorts — Rebuilt Screen Reference

This folder contains a **new, approximate reconstruction** of the supplied AI Shorts screen as a responsive static HTML/CSS/JavaScript page.

## Important source-file note
The original editable source files used to generate the reference image were **not available**. Nothing here is claimed to be recovered original source. These files were recreated from the screenshot reference.

## Files
- `index.html` — page structure and Arabic interface copy.
- `styles.css` — responsive layout, dark theme, gradients, panels, and controls.
- `colors.css` — extracted/reconstructed color tokens for easier adjustment.
- `app.js` — small demo interactions for tabs, selected reference card, prompt character count, and sample prompt.
- `assets/feature-art.svg` — newly drawn abstract placeholder artwork for the model banner; it is not the original artwork.

## Preview
Open `index.html` in a modern browser. Google Fonts is used for Noto Sans Arabic when internet access is available; a system font fallback is included.

## Limitations
This is a visual starting point, not a pixel-perfect copy. Some symbols are text glyphs, and the original photographic thumbnails are not available as separate source assets. Video generation, uploads, advanced settings, billing, and backend/API integration are not implemented.
