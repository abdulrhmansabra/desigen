# الصورة المرجعية الأصلية

الصورة المرجعية الأصلية المرفقة من المستخدم أبعادها 716 × 1536 بكسل، وتم حفظها كما هي داخل ملف ZIP القابل للتنزيل بجانب مجلد `REFERENCE_SOURCE`.

لم تُستخدم الصورة كخلفية لملف `SOURCE/screen_recreation.svg`: ملف SVG هو إعادة رسم مستقلة للواجهة، والمرجع مخصص للمقارنة البصرية فقط.

ملاحظة: أداة GitHub المتاحة في هذه الجلسة تنشئ ملفات نصية فقط؛ لذلك لا أزعم أن ملف PNG الثنائي نفسه قد رُفع إلى المستودع. النسخة المحلية ZIP تحتوي على الصورة الأصلية.
