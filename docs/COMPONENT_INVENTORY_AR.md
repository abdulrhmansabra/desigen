# جرد المكونات

## Foundations
- ألوان الخلفية والأسطح والنصوص والحدود والحالات.
- التدرج الرئيسي والتدرج الداكن.
- أحجام الخطوط والأوزان والمسافات ونصف قطر الزوايا.
- انتقالات الحركة والظلال.

## Actions
- Primary gradient button
- Secondary / outline / ghost / light / destructive buttons
- Small / default / large / full-width / disabled buttons
- Circular icon buttons / create button
- Badges: new, premium, success, warning, error
- Filter chips and removable chips
