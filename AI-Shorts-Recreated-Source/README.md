# AI Shorts — Reconstructed UI Source

This folder is a **reconstruction** of the AI video-generation screen shown in the supplied reference screenshot. It is not the original source project used to produce any prior generated mockup.

## Files
- `index.html` — screen structure and Arabic RTL layout.
- `styles.css` — responsive styling, colors, gradients, and component states.
- `design-tokens.css` — centralized color, spacing, radius, and typography tokens.
- `app.js` — small demo interactions for tabs, reference slots, prompt counter, and create button.
- `assets/ai-shorts-mark.svg` — recreated simple vector mark, not an extracted original logo.

## Visual direction
- Near-black / deep navy base.
- Restrained soft gradient from lavender-purple to pale pink.
- Cool muted gray for secondary labels.
- Cyan is used only for the required-reference indicator, matching the source screen's functional accent.
- No heavy outer glow; borders and gradients are subtle.

## Assets and provenance
**Recovered original files:** none. No source files, design files, original font files, original icon set, or original image assets for the generated mockup were available in this conversation or retrieved from the repository during this task.

**Recreated here:** HTML, CSS, design tokens, demo JavaScript, and a simple SVG brand mark. The screenshot is treated as a visual reference, not as an editable source file. The portrait/landscape thumbnails are represented with styled placeholders because the original image assets were not available as separate files.

## Run
Open `index.html` directly in a modern browser. No build system or package installation is required. This is a web reconstruction/prototype, not a native Android/Jetpack Compose implementation.
