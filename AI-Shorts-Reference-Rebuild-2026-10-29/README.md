# AI Shorts — Reference Screen Rebuild

A self-contained, editable HTML/CSS/JavaScript reconstruction of the Arabic AI video-generation screen shown in the supplied reference image.

## Important source provenance

**This is reconstructed source, not recovered original source.** The repository was inspected before this package was added. The available related directories contain reconstruction notes and hand-authored assets; no verifiable original Figma/PSD design file, original app screen source, native project export, or source package that created this exact screenshot was found. Existing files have not been relabelled as originals.

The layout, spacing, palette, visible Arabic copy, UI controls and approximate artwork in this folder were rebuilt from the screenshot. The woman/landscape thumbnails are new vector illustrations and are not the original screenshot photographs. The interface is a visual prototype: generating videos, billing, selecting a real model, and uploading real files are not connected to a service.

## Contents

- index.html — complete Arabic RTL screen structure.
- css/design-tokens.css — color, radius, spacing and typography tokens.
- css/styles.css — responsive layout and component styling.
- js/app.js — local prototype interactions and accessible feedback.
- assets/icons.svg — reusable, single-color SVG icon sprite.
- assets/feature-art.svg — newly drawn vector artwork for the model banner.
- assets/reference-one.svg, reference-two.svg, reference-three.svg — newly drawn reference thumbnails.
- FONTS.md — font stack and font-source status.
- docs/RECONSTRUCTION-PROVENANCE-AR.md — restored-vs-recreated inventory in Arabic.
- docs/DESIGN-SPEC-AR.md — implementation notes and visual tokens.
- package.json — optional local preview command using Vite.

## Run

Recommended:
1. Open a terminal in this directory.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.

No build step is required for the HTML/CSS/JS itself. You can also open index.html directly, although a local server is more reliable for loading SVG sprite symbols.

## Scope and limitations

The prototype aims to match the composition and visual identity of the reference rather than reproduce pixels generated by an unavailable original project. It uses CSS gradients and newly drawn SVGs so there are no runtime image-CDN dependencies. No external fonts or font files are bundled. Buttons provide demonstrative local UI feedback only; they do not generate media or send user data.
