## Important

The user-provided screenshot is a rendered reference, not the original source project. It cannot reveal exact original layout constraints, font metadata, vector paths, or image files. No recreated file in this folder should be described as recovered original source.

For closest visual matching, replace the illustrative icon paths with app assets if those assets exist, and pass the original portrait and thumbnails into the Compose component slots.
