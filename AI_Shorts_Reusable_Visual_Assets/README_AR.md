# AI Shorts — أصول بصرية قابلة لإعادة الاستخدام

هذه الحزمة تضيف أصول SVG متجهية قابلة للتعديل مباشرة داخل المستودع، باستخدام الهوية المعتمدة: خلفية فحمية/كحلية مع تدرج بنفسجي ووردي ولمسة زرقاء.

## الملفات
- `SVG/screen_background.svg`: خلفية شاشة مع إضاءة محيطية خفيفة أعلى الشاشة.
- `SVG/gradient_cta_button.svg`: سطح زر التدرج الرئيسي.
- `SVG/pro_banner_panel.svg`: سطح بانر Pro.
- `SVG/model_selector_panel.svg`: سطح بطاقة اختيار النموذج.
- `SVG/reference_slot_optional.svg`: إطار مرجع اختياري.
- `SVG/reference_slot_required.svg`: إطار مرجع مطلوب.
- `SVG/prompt_panel.svg`: سطح حاوية المطالبة.
- `SVG/prompt_input_inner.svg`: سطح حقل الإدخال الداخلي.
- `SVG/setting_chip.svg`: سطح خيار إعداد.
- `SVG/sparkle_icon.svg` و`SVG/image_add_icon.svg` و`SVG/plus_icon.svg`: رموز متجهية.
- `PALETTE.txt`: قيم ألوان الهوية.

## ملاحظات
- ملفات SVG متجهية، ويمكن فتحها وتعديلها في محررات تدعم SVG أو استيرادها في أدوات التصميم.
- هذه ملفات أصول بصرية، وليست بديلًا عن مكونات Jetpack Compose.
- ملف PSD أصلي أو ملف ORA/PNG ثنائي لا يمكن رفعه عبر إجراء إنشاء ملفات النصوص المستخدم هنا؛ لذلك أضيفت الأصول المتجهية القابلة للتحرير مباشرةً إلى المستودع.
