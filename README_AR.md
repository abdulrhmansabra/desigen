# PixVerse-inspired UI Component Library — v2.0

## ما الذي تم إنجازه؟
هذه مكتبة واجهات أكبر ومنظمة إلى أقسام، وليست لقطة تصميم واحدة. افتح `index.html` لمعاينة كتالوج المكونات.

### محتويات الحزمة
- `index.html`: كتالوج تفاعلي متجاوب بالعربية وRTL.
- `css/tokens.css`: متغيرات الألوان والمسافات والزوايا والخطوط.
- `css/components.css`: الأنماط القابلة لإعادة الاستخدام.
- `js/components.js`: تفاعلات تجريبية للتبويبات والتنقل.
- `tokens/design-tokens.json`: تصميم Tokens بصيغة JSON لتسهيل تحويلها لأدوات أخرى.
- `docs/RESEARCH_NOTES_AR.md`: ما تم التحقق منه من المصادر الرسمية وما لا يمكن تأكيده.
- `docs/COMPONENT_INVENTORY_AR.md`: جرد المكونات المقترحة.
- `docs/ANDROID_MAPPING_AR.md`: خريطة نقل المكونات إلى Android.
- `android-reference/`: أمثلة مرجعية أولية لـ Compose وXML.

## الاستخدام
1. فك الضغط.
2. افتح `index.html` في Chrome أو Edge.
3. انسخ المكون المطلوب من HTML واربطه بـ `css/components.css`.
4. عدّل الألوان والقياسات من `css/tokens.css` أو `tokens/design-tokens.json`.

## الدقة والحدود
الحزمة **مستوحاة من PixVerse وليست رسمية ولا تدعي مطابقة التطبيق بكسلًا ببكسل**. استند التحليل إلى صفحة التطبيق الرسمية على Google Play، وصفحة تنزيل التطبيق الرسمية، وصفحات المساعدة العامة، وإلى لقطة الشاشة التي قدمها المستخدم. بعض التفاصيل مثل شكل صفحات إنشاء الفيديو في إصدار المستخدم تحتاج لقطات شاشة إضافية من التطبيق الفعلي.

## Android
هذه الحزمة مرجع ويب؛ ملفات Android المرجعية أمثلة بداية وليست تطبيقًا متكاملًا. لتطبيق فعلي يجب اختيار تقنية المشروع (Jetpack Compose أو XML Views) وربط المكونات بمنطق التطبيق وخدماته.
